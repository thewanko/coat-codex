## 2026-11-03 typecheck-gate 模擬入力でしか試していないゲートを、効く前提で文書に書いていた [BAD]

- 事象: impl の終了時に型エラーで差し戻す hook を、模擬入力のテストだけで「1回だけ差し戻す」と skill に書いた。本物の impl で試すと、hook は exit 2 を返すのに impl は先に報告（SubagentHandback）を返して終了しており、差し戻しは届かなかった（フロントマターと settings.json の SubagentStop の両方で同じ）。計測用の trap で `$?` の前に `$(date)` を展開し、exit 2 を 0 と誤記録して遠回りもした。

- 反映先: `goal-loop` skill の「出口ゲート」（1件目「全体を検査するゲートはエラーを入れて確かめる」と同じ根本原因の2回目として昇格）
